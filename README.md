# nanoSecretary

一个跑在桌面的**本地 AI 秘书**。悬浮球常驻屏幕，随手记一句，AI 自动识别待办和截止日期，到点提醒你，还能直接对话。

所有 AI 能力由本地模型（Ollama）驱动，**数据不出本机**，隐私友好。

![悬浮球](./icon.png)

## ✨ 功能

- **悬浮球速记**：双击悬浮球弹出输入框，随手记，`Esc` 收起
- **AI 智能解析**：自动从一句话里提取待办内容、截止日期、优先级，并分类
  - 例：「下周三交季度报告」→ 待办「交季度报告」，截止 `2026-09-02`
- **到期提醒**：临近截止时通过系统通知 + 悬浮球变色 + 托盘提示提醒你，提醒文案由 AI 生成
- **对话式创建任务**：直接跟它说「帮我新建一个明天下午3点的任务，完成英语作业」，它会真正写入待办
- **待办管理**：主页面按截止日期排序展示待办，支持标记完成、改期、删除
- **历史记录**：按状态 / 分类 / 标签筛选，随时回顾
- **完全本地**：所有文本通过 Ollama 本地模型处理，不上传云端

## 📦 安装

### 方式一：直接运行打包版（推荐）

从 [Releases](../../releases) 下载最新版，解压后双击 `nanoSecretary.exe` 即可运行（免安装）。

### 方式二：从源码运行

需要 [Node.js](https://nodejs.org) 和 [Ollama](https://ollama.com)。

```bash
# 1. 安装依赖
npm install

# 2. 安装 Ollama 并拉取模型（任选一个小模型即可）
ollama pull qwen2.5:3b

# 3. 启动
npm start
```

> 提示：设置面板里可以切换模型、调整提醒提前量。若默认模型未安装，对话时会自动切换到已安装的模型。

## 🚀 使用指南

| 操作 | 方法 |
|---|---|
| 记一件事 | 双击悬浮球 → 输入 → 回车保存 |
| 查看待办 | 悬浮球右键 → 主页面 |
| 问 AI | 主页面 → 💬 对话 Tab |
| 管理历史 | 悬浮球右键 → 历史记录 |
| 拖到别处 | 按住悬浮球拖动，位置会记住 |
| 开机自启 | 悬浮球右键 → 勾选「开机自启」 |

**随手记的例子：**

```
下周三交季度报告            → 待办，截止下周三
明天上午10点去医院 #健康     → 待办，带分类
8月31日前给客户发合同       → 待办，截止 8-31
记得买牛奶                 → 备忘（无日期）
```

## ⚙️ 设置

主页面 → 设置：

- **Ollama 模型**：下拉选择本地已安装的模型
- **提醒提前量**：截止前多少小时开始提醒（0 = 仅当天提醒）
- **AI 智能解析**：关闭后仅保存文本，不做 AI 提取

## 🤝 常见问题

**Q：页面显示「AI 离线」？**
确认 Ollama 已启动（托盘有 Ollama 图标），且已安装至少一个模型。离线时记东西、待办、提醒仍可用，只是 AI 解析和对话不可用。

**Q：对话说「本地模型暂时不可用」？**
默认模型 `qwen2.5:3b` 可能未安装。在设置里选择一个已安装的模型，或运行 `ollama pull qwen2.5:3b`。

**Q：数据存在哪里？会不会上传？**
所有数据都存在本地 `history_files/`，AI 调用走本地 Ollama，不联网、不上传。
